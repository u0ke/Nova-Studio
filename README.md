# NOVA Studio

A simple ecommerce landing page for a fictional lifestyle brand.

## About

NOVA is a small frontend project focused on clean design, everyday products, and a minimal shopping experience.

## Features

- Responsive layout
- Light and dark mode
- Product collection section
- About section
- Newsletter form
- Mobile navigation

## Built With

- HTML
- Tailwind CSS
- JavaScript
- Flaticon Icons

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/u0ke/Nova-Studio.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser, or use Live Server in VS Code.

## Preview

Open `index.html` to explore the website.
